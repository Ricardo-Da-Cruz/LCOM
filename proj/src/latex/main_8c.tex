\doxysubsection{Detailed Description}
Ponto de entrada principal e controle de fluxo do programa Pac-\/\+Man. 

Este arquivo contém a estrutura principal do programa, implementando\+:
\begin{DoxyItemize}
\item Inicialização do sistema LCF (LCOM Framework)
\item Configuração de interrupções de hardware (teclado, timer, mouse)
\item Máquina de estados principal do programa (MENU, PLAYING, SCORE, EXIT)
\item Gerenciamento de transições entre diferentes estados do jogo
\item Inicialização do modo gráfico e recursos do sistema
\item Sistema de pontuação e persistência de scores em arquivo
\item Limpeza de recursos e finalização adequada do programa
\end{DoxyItemize}

O programa utiliza uma arquitetura baseada em máquina de estados, onde cada estado representa uma fase diferente da aplicação (menu principal, jogo ativo, tela de pontuações, etc.). A comunicação entre estados é feita através de códigos de retorno das funções de cada estado.

A inicialização inclui configuração de interrupções de hardware necessárias para input do usuário (teclado e mouse) e temporização (timer), bem como a configuração do modo gráfico VBE para renderização.

\begin{DoxyNote}{Note}
O programa utiliza o framework LCF para abstração de hardware específico do MINIX, facilitando o desenvolvimento de aplicações em modo protegido. 

A frequência do timer é configurada para 60Hz para gameplay suave.
\end{DoxyNote}
